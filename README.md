# Indicadores de Desempenho das UBSs - Potim/SP (2023)
Este projeto tem como objetivo apresentar visualizações interativas dos indicadores de desempenho das Unidades Básicas de Saúde (UBSs) do município de Potim/SP ao longo do ano de 2023. Os gráficos foram desenvolvidos em Python utilizando bibliotecas como pandas, matplotlib e numpy.

# Sobre o projeto
O código permite:

-Carregar e tratar dados trimestrais dos indicadores de UBSs.
-Gerar gráficos horizontais para análise de desempenho por quadrimestre.
-Gerar gráficos comparativos por UBS ao longo do ano.
Os gráficos facilitam a leitura dos dados, com anotações e cores distintas para cada período, permitindo identificar facilmente avanços e retrocessos nos indicadores.

# Exemplos de visualização
Os dados apresentados são fictícios e utilizados apenas para fins demonstrativos.
