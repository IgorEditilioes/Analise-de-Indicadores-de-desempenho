# Analise-de-Indicadores-de-desempenho
Este projeto apresenta gráficos com os indicadores de desempenho das Unidades Básicas de Saúde (UBSs), com base em dados públicos do e-Gestor AB. Os gráficos permitem visualizar e comparar o desempenho por UBS e por quadrimestre, facilitando a análise e tomada de decisão.
